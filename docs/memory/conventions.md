# Memory Conventions

## File naming

- Runs: `YYYY-MM-DD-<slug>.md`
- Decisions: `ADR-YYYY-MM-DD-<slug>.md`
- Working notes: `active-<topic>.md`

## Minimal section schema for run logs

1. Objective
2. Context and sources
3. Actions
4. Files changed
5. Validation
6. Risks / unknowns
7. Handoff

## Style

- Be concise and specific.
- Prefer bullets over long prose.
- Link to artifacts instead of restating content.
- Keep inference distinct from sourced fact.
