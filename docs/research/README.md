# Research Hub

Research in this repo should be source-grounded and durable.

## Standard output shape

Use [`templates/research-brief.md`](templates/research-brief.md) for substantial research. Shorter answers can still follow the same structure:

- question;
- date and freshness window;
- sources consulted;
- claim/evidence table;
- analysis and recommendation;
- risks and unknowns;
- next actions.

## Freshness rule

For fast-moving AI tooling, prefer sources from the last 45 days. If older sources are used, say why they are still relevant.
